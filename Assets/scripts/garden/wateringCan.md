# Описание работы полива лейки (WateringCan)

## Краткое резюме
Лейка (`WateringCan`) наследует от `DragDrop` и реализует полив цветов при отпускании мыши. Полив происходит через физический запрос `Physics2D.OverlapBoxAll`, который ищет все коллайдеры, находящиеся в небольшом квадрате под лейкой, и вызывает у найденных объектов метод `Water()`.

## Последовательность действий в `OnMouseUp`
1. **Определение слоя растений**
   ```csharp
   int plantLayerMask = LayerMask.GetMask("plant");
   ```
   Формируется битовая маска, содержащая только слой с именем **Plant**. Запрос будет обрабатывать только коллайдеры, принадлежащие этому слою.

2. **Физический запрос OverlapBoxAll**
   ```csharp
   Collider2D[] hitColliders = Physics2D.OverlapBoxAll(
       transform.position,      // центр квадрата – текущая позиция лейки
       _checkHalfSize,          // половина размеров проверочного квадрата (по‑умолчанию 0.5 × 0.5 → квадрат 1 × 1)
       0f,                      // угол вращения – без вращения
       plantLayerMask           // маска – только слой Plant
   );
   ```
   Запрос возвращает массив всех `Collider2D`, которые пересекаются с указанным квадратом.

3. **Перебор найденных коллайдеров**
   ```csharp
   foreach (Collider2D col in hitColliders)
   {
       if (col.TryGetComponent<Flower>(out Flower plant))
       {
           plant.Water();
       }
   }
   ```
   Для каждого найденного коллайдера проверяется наличие компонента `Flower`. Если он есть – вызывается `Water()`, тем самым поливая цветок.

4. **Обработку случая, когда ничего не найдено**
   ```csharp
   if (hitColliders.Length == 0)
       transform.position = _startPosition;
   ```
   Если в зоне полива нет ни одного цветка, лейка возвращается в исходную позицию (`_startPosition`).

## Важные детали, влияющие на поиск
| Параметр | Почему важен | Как проверить/настроить |
|----------|--------------|--------------------------|
| `_checkHalfSize` | Размер зоны полива. Если слишком мал, лейка может «промахнуться». | Увеличить значение в коде или сделать его динамичным (использовать `bounds.extents`). |
| Слой `Plant` | Опрос ограничен только этим слоем. Цветок на другом слое не будет найден. | В инспекторе у всех объектов‑цветов установить слой **Plant**. |
| `Collider2D` у цветка | `OverlapBoxAll` возвращает только коллайдеры. Без коллайдера цветок не будет найден. | Убедиться, что у цветка (или его дочернего объекта) есть активный `Collider2D`. |
| `Collider2D` лейки – `Is Trigger` | Требование скрипта; если выключено, могут возникнуть конфликты с физикой. | В инспекторе у коллайдера лейки включить **Is Trigger**. |
| `Rigidbody2D` лейки – тип `Kinematic` | Динамический rigidbody может оттолкнуть лейку до `OnMouseUp`. | В инспекторе у `Rigidbody2D` задать **Body Type = Kinematic** (скрипт может автоматически исправить). |
| Иерархия цветка | Коллайдер может находиться на дочернем объекте, но он всё равно будет найден, если включён и находится на слое Plant. | Открыть сцену, включить Gizmos, убедиться, что в зоне полива покрыт нужный дочерний коллайдер. |

## Визуальная отладка
- В `OnDrawGizmosSelected` рисуется голубой (cyan) куб, отражающий проверочную область. В режиме Play включите **Gizmos**, чтобы увидеть, покрывает ли куб цветок.
- Откройте **Window → 2D → Physics 2D Debugger → Colliders** и убедитесь, что коллайдеры цветов зарегистрированы.

## Частые причины, почему лейка не поливает
1. Цветок находится не на слое **Plant**.  
2. У цветка нет активного `Collider2D`.  
3. Размер `_checkHalfSize` слишком мал / центр лейки смещён.  
4. Лейка имеет обычный (не‑триггерный) коллайдер или `Rigidbody2D` типа **Dynamic**.  
5. `OnMouseUp` не вызывается (например, из‑за конфликтов с UI‑EventSystem).  

## Как быстро проверить
1. Откройте сцену в Play‑mode.  
2. Включите Gizmos – наблюдайте за cyan‑квадратом.  
3. Перетащите лейку над цветком, отпустите мышь.  
4. В консоли должны появиться сообщения:  
   - `"[WateringCan] OnMouseUp at ..."`  
   - `"[WateringCan] Found N potential objects in overlap area."`  
   - `"[WateringCan] Watering flower '<имя>'"`  
Если сообщения отсутствуют – проверьте пункты из раздела **Важные детали**.
