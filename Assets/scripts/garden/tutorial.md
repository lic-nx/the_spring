Это инструкция как настраивать сцену.
# Настройки  роста цветка (Growth Conditions)
чтоб создать семена нужно в папке garden нажать на правую кнопку мыши. после появится меню. в нем нужно выбрать Create->Garden->Growth Conditions
появится префаб настроек. 
что указываем
 - передаем список спрайтов для изменения цветка. можно указать сколько угодно. цветок перестанет расти как только дойдет до последнего спрайта
 - Time between watering - это время которое должно пройти между поливами. 
 - дальше указываем сколько времени проходит между выдачей валюты(солнышка)
 - Указываем какую сумму нам даст солнышки от этого цветка
 - Base Evetn Count - сколько должно произлойти событий(в нашем случае сколько должно пройти поливов) чтоб перейти на следующую стадию. 
 - Stage Multiplier - это во сколько раз увеличивается число необходимых поливов чтоб перейти на следующую стадию. 

# Семена (Seeds) (Seed item)
чтоб создать семена нужно в папке garden нажать на правую кнопку мыши. после появится меню. в нем нужно выбрать Create->Garden->Seed Item. 
 появится объект SeedItem у которого указываем:
 - название цветка, 
 - префаб цветка, ( берем для всех один и тот же. префаб называется Flower)
 - после передаем настройки для цветков(Growth Conditions) 
 - Указываем вероятность выпадания цветов при посадке 
 - спрайт для семян
 - стоимость

 Это основные настраиваемые объекты
